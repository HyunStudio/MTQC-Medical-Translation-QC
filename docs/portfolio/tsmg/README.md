## Public website setup (GitHub Pages)

The source is committed at `docs/portfolio/tsmg/index.html`.

1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Set **Branch: main**, **Folder: /docs**, then save.
4. Verify the public URL in a logged-out browser before adding it to a job application:
   `https://hyunstudio.github.io/MTQC-Medical-Translation-QC/portfolio/tsmg/`

This link is a *proposed Pages address*, not confirmed live until GitHub Pages is activated and an unauthenticated access check succeeds. Publishing `/docs` may also make other already-public documentation under that directory available as pages.
