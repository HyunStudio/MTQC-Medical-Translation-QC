## What changed, with failure-first evidence

1. **Centered five-column, one-data-row table.** Kalluvila et al., *Diagnostics* (2025), DOI [10.3390/diagnostics15233046](https://doi.org/10.3390/diagnostics15233046), physical page 8, has a visibly single-column page with Table 1 at the top. The table headers are `UNet++ | U-Net | Nested U-Net | Attention U-Net | Trans U-Net`; the one rating row is `3.1 ± 0.32 | 3.6 ± 0.52 | 3.7 ± 0.67 | 3.7 ± 0.82*† | 2.0 ± 0.0`. The previous automatic proposal split the first two columns from the last three and interposed a dagger footnote. A regression copied the relevant **original PDF.js text fragments and rounded coordinates** into `src/web_demo_browser_tests/layout.test.mjs` with source attribution. It failed with zero detected table regions. The narrow correction recognizes only a centered, half-page-spanning header with at least five compact labels and an immediately following, horizontally aligned numeric row. It emits one table band, one header line, and one rating line; the following `3.3. Qualitative Comparison` remains after the table. The existing left-aligned long-table path is unchanged. This is a reading-order proposal, **not cell-level semantic parsing or medical validation**.
2. **Table end absorbing the next two-column paragraph.** Separate synthetic regressions established a real algorithmic failure for both the old multi-row path and the new centered one-row path: a table ending around y=130/110 respectively swallowed left/right prose starting 23 px below its last row and interleaved it on one line. Both tests failed before their fixes and passed after ending each table band at the actual last data-cell bounding box plus 2 px. On Kalluvila page 8, the footnote remains a separate readable line after the table and before `3.3. Qualitative Comparison`. The boundary correction did not alter any other original-page text in the six-page replay. It is a guarded synthetic fix, not a new observed failure on those published pages.
3. **Preview versus application state.** In a real-browser regression, changing the reading-order selector preserved edited text and approval, but the summary did not say that the new overlay was only a proposal. The new test failed before the copy change and passed after the summary began saying `Preview only; excerpt and review approval are unchanged` on selector changes, and `Applied to excerpt; review approval reset` after explicit replacement. The underlying approval behavior was not changed.
