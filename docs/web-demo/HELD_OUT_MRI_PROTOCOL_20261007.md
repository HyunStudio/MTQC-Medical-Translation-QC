## Mechanical page selection, before any page inspection

For each final publisher/PMC PDF, scan its selectable text layer programmatically in physical page order (1-based). Exclude only title/abstract-only page 1 and pages whose extracted text begins with `References`, `Supplementary`, or `Acknowledgments`. A caption candidate is a line beginning, case-insensitively, with `Fig.`, `Figure`, or `Table` followed by a number. First select the earliest eligible page with a **figure** caption for Kalluvila, or a **table** caption for Rankin/Bhalerao. Second select the earliest *different* eligible page with the opposite caption type. If that type is absent, select the immediately following eligible physical page, otherwise the preceding eligible page. If neither caption type is detected, select physical pages 2–3 (or the available eligible pages) and mark caption-target failure. When the preferred caption and opposite caption occur on one page, pair it with the next eligible page (otherwise previous). Never replace a selected page because its output looks poor. A two-page excerpt may combine nonadjacent original pages; preserve their original page numbers in the report and screenshot labels.

Each excerpt must preserve the original pages without lossy image recompression and satisfy both app limits. If the official final PDF is unavailable, page selection cannot be applied, excerpt exceeds 10 MiB, a page exceeds the rendering guard, or the article cannot be identified as the final version, mark the candidate attempted-but-excluded with exact reason. Do not silently substitute a preprint, change resolution, or choose an easier page. If only one eligible page exists, attempt it as a one-page excerpt and record the deviation from the intended two-page sample.

## Visual truth and scoring, independent of output

For every selected page, render the original first and freeze a page checklist **before** viewing baseline or enhanced output. Enumerate every visible heading, prose column, figure and caption, table and caption, displayed equation, unit-bearing expression, and rotated/raster text region. For prose, annotate first and last substantive line of each column and every transition across a full-width element. For tables, annotate the header labels and **every visible data row** as row-to-value and value-to-column associations; if the table is truncated across pages, mark each absent portion unscorable rather than guessing. For each figure, annotate its caption association and whether image-internal labels are selectable or raster-only. Mark all formulas and units in these enumerated regions. Record bounding boxes or a visually labeled screenshot so another reviewer can audit the truth items.

Score both arms on the same truth-item IDs: `reading_order`, `omission_or_duplicate`, `table_row_column_value`, `caption_figure`, `formula_or_unit`, and `rotated_or_raster_text`. Item outcomes are `pass`, `fail`, or `unscorable` with evidence; a category with no source instance is `not_present`, not a pass. Count attempted candidates, attempted pages, scorable items, unscorable items, and excluded candidates separately. Report raw numerators/denominators and failure examples, not an aggregate accuracy claim. Fragment retention in a text layer does not count as correct reading order, table semantics, or raster-label recovery.

P0 is a reproducible privacy/review-gate violation or material content corruption presented as verified. P1 is a reproducible structural relation failure (e.g., a wrong table row/value association, column-order split, or figure-caption detachment) that a reviewer could mistake for faithful extraction. Record the smallest case, expected behavior, actual behavior, cause, and whether the same failure occurs in the simple baseline. Do not expand an allowlist to hide a failure. Any code fix requires a failing regression first, the minimal correction, and rerun of related tests and CI before a completion claim.

Do not call Nebius without contemporaneous human approval. If offline QC is included, use only existing saved genuine model drafts or clearly labeled synthetic adversarial source/draft pairs for negation, dosage, units, numbers, and terminology; report those as rule behavior, not live multilingual translation quality. GPT-only review is not independent expert adjudication.
